    A few screenshots. One story.

    1. Add screenshots in reading order.Use PNG, JPG or WebP. Drag to reorder, use the up/down buttons, or sort by filename. Existing screenshots stay in place when you add more.
    2. Trim fixed interface bars.Select a screenshot and set its top/bottom/left/right crop in source pixels. Remove repeated headers, keyboards and navigation bars before matching. Cropping, adding, removing or reordering resets joins.
    3. Find and inspect overlaps.Click Find overlaps. Strong matches are applied; uncertain matches are marked for review. If no reliable match is found, nothing is removed. Use the Joins tab to adjust overlap in common-width pixels. Inspect join shows the result around the seam.
    4. Save PNG, JPG or PDF.PNG is best for text. JPG makes a smaller re-encoded image. PDF splits the result into A4 or Letter image pages with an optional repeated strip at page breaks. The visible join guides are not exported.
    For good matches:screenshots should show the same content at the same zoom, with some overlap. Animated or changing content, sticky bars, blank areas and repeated patterns can confuse matching. This tool joins vertically; it does not capture a webpage, scroll another app or invent missing content.
    Image quality:images are fitted to a common width, capped at 4,096 px, without enlarging the smallest cropped image. Width changes can resample pixels. Outputs are newly rendered files, not byte-identical copies. Transparency is flattened onto white. No added watermarks.
    Limits:30 images, 25 MB per file, 20 megapixels per image and 60 megapixels per collection. PNG/JPG export is limited to 32 megapixels and 32,760 px per side; reduce the width or use PDF for longer results. PDF supports up to 200 pages. Animated PNG/WebP and other formats are not supported.
    Private and portable:the tool is one HTML file. No uploads, accounts, external scripts, tracking or network requests. Images and edits clear when the tab is closed or reloaded. Use an updated desktop browser. Undo covers crops, joins and ordering; adding or removing an image clears undo history.
